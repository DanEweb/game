# GRAYSCALE // SURVIVOR

친구가 만든 미니 뱀서류에서 시작해 디아블로/PoE 스타일 RPG로 진화 중인 브라우저 게임.
바닐라 JS + Canvas, 프레임워크·에셋 없이 단일 코드베이스로 동작합니다.

**플레이**: `index.html`을 브라우저로 열거나, 배포 URL 접속. 폰에서는 드래그 이동 + 화면 버튼.

## 주요 시스템
- 직업 16종 (히든/비밀 포함) + 직업 전용 테크·전용기(Q) + 스킬바(1~4)
- 무기 8종 + 진화 + 합성 + 원소 각인, 유일 성장 무기 4종 (파밍 재료로 제작/강화)
- 원소 속성 테크트리 7계열 (3속성 제한, 카드 등급 확률제, 잭팟)
- 운명 성도: PoE식 영구 패시브 트리 (~175노드, 순환로, 변혁 키스톤, 직업 공명)
- 장비: 8부위 / 희귀도 7단계(일반~태초) / 유니크·세트 / 강화 +9 / 저주 / 경갑·중갑
- 위험도 0~20 난이도, 랜덤 맵, 보스 17종(각성형·분노 페이즈), 엘리트 특수 패턴
- 조사 이벤트, 시련의 제단, 떠돌이 상인, NPC 의뢰인, 보물 골렘
- 퀘스트 10계열 / 업적 26종 / 절차 생성 BGM·SFX

## 개발
정적 사이트 — 빌드 불필요. 로컬 서버:
```bash
npx serve .
```

단일 HTML 파일로 묶기(카톡 공유용):
```bash
node build-single.mjs   # dist/gray_survivor_single.html 생성
```

## 저장 데이터
`localStorage["gray_survivor_v3"]` — 골드, 장비, 성도, 업적, 위험도 등 전부 로컬 저장.
